## 🚀 Featured Projects

### 📈 Real-time Event-Driven Stock Trading Decision Agent

[![Repository](https://img.shields.io/badge/GitHub-Repository-black?style=flat-square&logo=github)](https://github.com/FAU-wyl/flink-stock-analysis-agent)

An autonomous real-time analysis and decision-making agent built with the Flink Agents framework.

- Designed a two-stage workflow: technical analysis → trading decision
- Implemented RSI, MACD, position query and simulated trading tools
- Added perception memory for cross-action state passing
- Added short-term memory for persistent position state across ticks
- Supports remote model APIs and local Ollama deployment
- Integrated Tool Calling, Skills and multi-agent collaboration

### 🎮 Batch Grant Entitlements — Electronic Arts

A full-stack and AI engineering project for batch self-service authorization of EA game entitlements.

- Owned the development of a one-stop web-based batch authorization system
- Supported file upload, visual workflows and automated reports
- Replaced multi-team ticket-based processes and manual scripts
- Designed a layered backend architecture:
  `Routes → Controllers → Services → Clients`
- Built an asynchronous Worker Pool model for 100K-level ID batch processing
- Added concurrency protection with a maximum of 100 concurrent requests
- Used pessimistic and optimistic locking to maintain data consistency
- Exposed seven REST APIs as MCP Tools, Resources and Prompts
- Added confirmation annotations for sensitive tools
- Provided streaming communication through Streamable HTTP

**Tech:** TypeScript · React · Java · Spring Boot · MCP

---

### 📊 Business Target Forecasting and Management Platform - MeiTuan

A web-based platform that productized a previously manual Excel-based forecasting workflow.

- Built parameter management and result versioning with Spring Boot and MySQL
- Supported parameter comparison, rollback and historical traceability
- Migrated standalone Excel algorithms to PySpark on a distributed cluster
- Automated the workflow:
  `Parameter Configuration → Algorithm Execution → Result Persistence`
- Improved forecasting efficiency by more than 70%
- Saved approximately 10 person-days of monthly manual work

**Tech:** Hadoop · Spark · Flink · Doris · Spring Boot · MySQL · PySpark
